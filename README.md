# CU ML Club

Сайт ML-клуба Cardiff University Kazakhstan (Астана): события клуба, команда и форма «Join the team».

Главная фишка — 3D робот-осьминог (three.js), талисман клуба. Он заплывает на страницу,
вытягивает кнопку **Events**, раскидывает карточки событий и раскладывает их на полку по датам.
Фильтры: осьминог убирает лишние карточки обратно в кнопку Events и достаёт нужные.
По кнопке **Team** тянет кнопку Team и задёргивает «занавес» с командой (карточки остаются на полке);
первый скролл или свайп — и он его отпускает.
Когда листаешь от событий к блоку с логотипом, осьминог ползёт по экрану вместе с прокруткой
(по волнистой траектории, постепенно уменьшаясь) и «ныряет» в пустую рамку — на его месте появляется
нарисованный логотип. При прокрутке обратно он вылезает и ползёт назад на полку.
Если листать дальше к команде, он вылезает из логотипа, ползёт к блоку Team и протягивает по руке
к аватарке каждого участника (руки идут по краям, не закрывая текст); подключённые карточки подсвечиваются.

Сайт на двух языках: русский и английский, переключатель RU/EN в меню. По умолчанию язык берётся
из браузера, выбор запоминается.

Это прототип: события и имена — примеры, формы сохраняются только в браузере (localStorage).

## Запуск

Сборка не нужна, это обычный статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере.

## Структура

```
index.html          разметка страницы
css/style.css       стили
js/data.js          данные: события, команда, варианты в формах  ← правится чаще всего
js/i18n.js          тексты интерфейса на английском и русском
js/app.js           логика: осьминог, полка с карточками, фильтры, окно события, формы
assets/logo.jpg     иконка клуба (логотип и favicon)
assets/octopus.webp картинка осьминога, если у браузера нет WebGL
vendor/three.min.js three.js r128 (MIT, лицензия рядом)
```

## Как поменять контент

Всё в `js/data.js`, там же описаны поля. Тексты пишутся на двух языках: `{en: '...', ru: '...'}`;
простая строка покажется на обоих (удобно для имён и метрик). Кнопки, подписи и прочий
интерфейс — в `js/i18n.js`.


- **events** — события. `type`: `club` (хакатон клуба), `webinar` или `community` (студенческий проект).
  Дата в формате `'2026-12-05T10:00'`, на полке карточки сами сортируются по дате.
- **team** — команда: имя, роль, пара слов.
- **help** — чекбоксы «How you want to help» в форме вступления.
- **roles** — роли по умолчанию для студенческих проектов.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: *Deploy from a branch* →
выбрать ветку и папку `/ (root)` → Save. Через минуту сайт будет на
`https://<username>.github.io/ML_Club/`.

## Что сейчас работает только в браузере

- Регистрация на событие и форма «Join the team» пишутся в `localStorage` под ключом `cuml-v1`,
  организаторы их не получают. Чтобы собирать заявки по-настоящему, нужен бэкенд:
  Google Forms / Google Sheets, Formspree или свой сервер.
- События и команда — примеры, их нужно заменить настоящими.

## Доступность и запасные режимы

- Без WebGL вместо 3D показывается статичная картинка, карточки сразу на полке.
- При включённом «уменьшении движения» (prefers-reduced-motion) анимация не проигрывается.
- На телефоне сцена вытягивается по высоте, чтобы осьминог был на всю ширину экрана.
